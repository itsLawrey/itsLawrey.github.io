# itsLawrey.github.io — Personal Portfolio

A personal portfolio website built with vanilla HTML, CSS, and JavaScript, hosted on GitHub Pages.

🌐 **Live site:** [itsLawrey.github.io](https://itsLawrey.github.io)

---

## Features

- **Responsive design** — mobile-friendly layout with a hamburger navigation menu
- **Smooth scrolling** — active nav link highlighting as you scroll through sections
- **Project showcase** — cards with tech tags and links to live demos and GitHub repos
- **Contact form modal** — powered by [Web3Forms](https://web3forms.com), with:
  - Client-side validation with real-time feedback
  - Honeypot + rate limiting for spam protection
  - Auto-close with progress bar on successful submission
- **Security headers** — strict Content Security Policy defined in the HTML

## Tech Stack

| Layer | Tech |
|-------|------|
| Markup | HTML5 |
| Styling | Vanilla CSS |
| Logic | Vanilla JavaScript |
| Form backend | Web3Forms API |
| Hosting | GitHub Pages |
